# FT8CN v0.93.005-beta.6 Pre-release Notes

## 测试预发布

此包仅用于 `v0.93.005-beta.6` 的测试预发布。它不是正式版，也不代表真实电台/HIL 已通过。

## 本次阻断收口

- 配置生命周期阻断的根因是测试立即断言异步 `DatabaseOpr.dbExecutor` 结果；`ActivityScenario.launch()` 不等待配置完成。临时 latch 占用共享 `diskIO` 后启动 Activity 可稳定复现 `expected:<1> but was:<0>`，证明是测试等待/隔离问题，不是已证实的 production 生命周期竞态。
- `MainActivityConfigLifecycleTest` 现在通过 `configLoadComplete` observer + bounded latch 等待真实完成事件，并在 finally 移除 observer；初始 Activity 与重建 Activity 的断言均经过明确完成边界。没有 skip、固定 sleep、放宽断言或 production 测试开关。
- 此外保留本 beta 候选已有的 HamRecorder stop→start ownership、真实 MicRecorder control instrumentation、AudioForegroundService production boundary 与 debug-only failure ACK、notes gate 等修复和边界。
