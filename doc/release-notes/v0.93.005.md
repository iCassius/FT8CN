# FT8CN v0.93.005 Release Notes

## 发布状态：阻断，当前仅允许 TEST/BETA

`v0.93.005` 当前是发布准备版本，不是可创建的正式 GitHub Release。正式发布必须先完成签名迁移确认；在用户明确选择并提供新的长期正式 keystore、可信证书 SHA-256 指纹和发布批准前，tag workflow 会 fail-fast，不创建正式 Release。

## 功能与稳定性改进

- 配置加载改为明确的“逐项读取 + 完成通知”状态模型；旋转、重建和损坏配置值不会把未完成加载当作可用状态。
- 发射流程由统一 PTT/SCO 协调器管理，断开连接、停止和延迟回调会安全收尾，避免生命周期切换中重复或遗漏恢复动作。
- 网络电台与音频任务使用有界串行队列、提交快照和会话 generation 隔离；TCP/UDP EOF、断线与旧回调不会污染新的连接状态。

- 基于 `ed64570` 代码树：JVM 8/8；AVD `connectedDebugAndroidTest` 43/43，失败 0、错误 0、跳过 0。

## 签名迁移说明

- 已公布的 `v0.93.004` APK 使用 Android Debug 证书；本仓库没有证明其对应私钥可恢复的证据，也不假设旧私钥可取回。
- Android 同包升级要求签名证书一致。任何新 formal key 都不能覆盖已安装的 `com.bg7yoz.ft8cn` v0.93.004；即使 `versionCode` 更高，也会被签名校验拒绝。
- 如果旧私钥不可恢复，本版本按“一次性签名迁移”处理。用户已批准采用卸载旧包后干净安装新签名包的方案，且 AVD 已完成实际干净安装；真实 Android 设备仍待实测。操作前仍应备份 ADIF/QSO 和可导出的配置，当前没有承诺自动迁移应用私有数据。
- TEST/BETA 使用 debug 证书和独立包名 `com.bg7yoz.ft8cn.beta`，仅用于测试和回退验证，不是正式版替代品。
