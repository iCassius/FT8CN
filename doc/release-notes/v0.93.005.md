# FT8CN v0.93.005 Release Notes

## 发布状态：正式发布仍阻断

本文件描述 `v0.93.005` 的正式候选源码与自动验证边界，不表示正式签名、tag 或 GitHub Release 已完成。正式发布必须先完成签名迁移确认；在用户明确选择并提供新的长期正式 keystore、可信证书 SHA-256 指纹和发布批准前，tag workflow 会 fail-fast，不创建正式 Release。

## 功能与稳定性改进

- 配置加载改为明确的“逐项读取 + 完成通知”状态模型；旋转、重建和损坏配置值不会把未完成加载当作可用状态。
- 发射流程由统一 PTT/SCO 协调器管理，断开连接、停止和延迟回调会安全收尾，避免生命周期切换中重复或遗漏恢复动作。
- 网络电台与音频任务使用有界串行队列、提交快照和会话 generation 隔离；TCP/UDP EOF、断线与旧回调不会污染新的连接状态。
- FT8 解码改为单飞协调和 epoch 生命周期隔离；重叠时隙跳过，空结果、异常和取消都有统一终态，旧解码结果不能污染新周期。
- 录音启动真值、Yaesu/FT-710 生命周期、Wavelog station ID 精确匹配和 JTDX priority 前置计算已修复；异步归属地刷新不重复计算 priority/会话统计。
- 保持 Android `minSdk 23`，修复发射任务集合的 API 兼容性；补齐希腊语、日语和西班牙语的新增界面字符串。
- 保留本地 TXT/ADIF `file/content` 导入 intent filter，并仅对该非 Web filter 做精准 `AppLinkUrlError` suppression。

- 已公布的 `v0.93.004` APK 使用 Android Debug 证书；本仓库没有证明其对应私钥可恢复的证据，也不假设旧私钥可取回。
- Android 同包升级要求签名证书一致。任何新 formal key 都不能覆盖已安装的 `com.bg7yoz.ft8cn` v0.93.004；即使 `versionCode` 更高，也会被签名校验拒绝。
- 如果旧私钥不可恢复，用户仍需明确选择是否采用“一次性签名迁移”，并确认卸载旧包后干净安装的方案。真实 Android 设备的迁移、数据备份和安装结果不属于本候选已完成的证据；操作前应备份 ADIF/QSO 和可导出的配置，当前没有承诺自动迁移应用私有数据。
