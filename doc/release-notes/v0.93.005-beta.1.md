# FT8CN v0.93.005-beta.1 Pre-release Notes

## 测试预发布

此包仅用于 `v0.93.005-beta.1` 的测试预发布。它不是正式版，也不代表真实电台/HIL 已通过。

## 本次改进

- 配置加载改为明确的完成状态，旋转、重建和损坏配置值不会把未完成加载当作可用状态。
- 发射流程由统一 PTT/SCO 协调器收尾，断连、停止和延迟回调会安全结束发射生命周期。
- 网络电台与音频使用有界队列、提交快照和会话 generation 隔离，TCP/UDP EOF 与旧回调不会污染新连接。

## 自动验证

- JVM：8/8 通过。
- AVD `connectedDebugAndroidTest`：43/43 通过，失败、错误、跳过均为 0。

## 使用边界

- 这是独立 beta 包名，可与正式包并存；不能代替正式签名发布。
- 使用前请备份 ADIF/QSO 和可导出的配置。应用私有数据不承诺自动迁移。
- 请在受控条件下继续验证 PTT、断线恢复、音频释放、长时稳定性、功耗和温升。
