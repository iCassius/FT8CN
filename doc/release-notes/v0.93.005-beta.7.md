# FT8CN v0.93.005-beta.7 Pre-release Notes

## 测试预发布

这是 `v0.93.005-beta.7` 的 beta-only 测试预发布候选，不是正式版，也不代表真实电台/HIL 已通过。此分支会创建发布链修复，但本会话不创建 tag 或 GitHub Release。

## 版本与包

- `versionName`：`0.93.005-beta.7`
- `versionCode`：`93007`
- 包名：`com.bg7yoz.ft8cn.beta`
- beta.7 产物必须使用专用的持久 beta-only certificate；普通本地 `debug` 仍可使用 Android Debug certificate。
- keystore、密码和 Actions secret 值不进入仓库、日志或本说明；formal 签名材料完全独立。

## 签名迁移

- beta.5 与 beta.6 使用过不同且不可作为持续升级链的签名身份；beta.6 的已发布 tag/Release 保持不可变，并标记为签名身份问题。
- beta.5/beta.6 用户升级到 beta.7 前需要卸载一次 `com.bg7yoz.ft8cn.beta`，这会清除该 beta 包的应用私有数据；请先按需导出/备份 QSO 与配置。
- 从 beta.7 开始，后续 beta 产物必须继续使用同一 beta-only certificate，才能通过 Android 覆盖升级。
- beta-only 身份只用于 `com.bg7yoz.ft8cn.beta` 测试包，绝不用于 `com.bg7yoz.ft8cn` formal 包。

## 验证边界

- 需要验证 tag/notes/versionName/versionCode/package、精确 certificate SHA-256、zipalign、JVM、Gradle 与独占 AVD 安装/启动证据。
- AVD 或自动化通过只属于 AUTO_VERIFIED/AVD_VERIFIED，不等同于真实手机、CAT/PTT/TX、完整 QSO、长时稳定性、功耗/温升或用户 HIL。
- formal gate、formal Secrets、formal tag 与 formal Release 独立；本说明不授权任何正式发布。
