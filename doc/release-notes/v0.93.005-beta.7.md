## 签名迁移

- beta.5 与 beta.6 使用过不同且不可作为持续升级链的签名身份，因此 beta.5→beta.6 不能覆盖升级；beta.6 的 live tag/Release 与 asset 保持不可变，并标记为签名身份问题。
- beta.5/beta.6 用户升级到 beta.7 前需要卸载一次 `com.bg7yoz.ft8cn.beta`，这会清除该 beta 包的应用私有数据；因此 beta.6→beta.7 也不能直接覆盖升级，请先按需导出/备份 QSO 与配置。
- 从 beta.7 开始，后续 beta 产物必须继续使用同一 beta-only certificate，才能通过 Android 覆盖升级。
- beta-only 身份只用于 `com.bg7yoz.ft8cn.beta` 测试包，绝不用于 `com.bg7yoz.ft8cn` formal 包。
