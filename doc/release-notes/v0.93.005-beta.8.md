## 16KB native 候选状态

- 当前集成来源：开发最终 SHA `9fbda6f99bb1395a429f32a936a1d9ea3b962327`，已将重建 native 源码接入生产构建路径；旧 `app/libs` 预编译库不再作为本候选的 native 来源。
- 独立测试结论：16KB native 自动化 `GO`，P0 `0`；严格 oracle 通过；四 ABI 的 ELF `PT_LOAD` 对齐均为 `0x4000`；JNI contract 为 31 个 required export + 2 个 optional export。
- 16KB AVD：API 37、`PAGE_SIZE=16384`、关闭 fatal compatibility mode 后启动成功；`connectedDebugAndroidTest` 为 63 pass / 1 intentional skip，AVD 已关闭。
- 4KB AVD 尚未完成；真实 Android 设备、真实电台、CAT/PTT/TX、完整 QSO、2 小时挂机、功耗和温升也尚未完成。自动化与 16KB AVD 证据不能升级为真机/HIL 或性能结论。

## Beta 发布门禁

GitHub Actions 必须从 `v0.93.005-beta.8` tag 构建，并核对 tag、`origin/codex/v0.93.005-integration` 精确 SHA、版本、包名、beta-only certificate、zipalign、四 ABI、JNI/ELF/16KB gate、JVM 和 APK metadata；门禁失败不得创建或修改 Release。实际 CI 签名成功前，beta.8 不能称为可发布资产。

正式 Release 仍为 `NO-GO`：本地没有受保护的 formal keystore、可信正式证书材料和正式发布批准。beta-only 与 formal signing 完全分离。
